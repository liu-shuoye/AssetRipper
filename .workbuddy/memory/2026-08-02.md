# 2026-08-02

## 新增"记住上次导出"功能（始终生效）
- 用户痛点：每次导出都要重新输入导出文件夹路径。
- 实现：新建 `AssetRipper.Export/Configuration/LastExportSettings.cs`（模型 + TryLoadFromDefaultPath/SaveToDefaultPath）与 `LastExportSettingsContext.cs`（AOT 源生成 JsonSerializerContext），落盘文件 `AssetRipper.LastExport.json`（程序执行目录）。
- 该记忆**不受现有 "Save settings to disk" 开关影响**，始终保存/加载。
- 串联点：`GameFileLoader.LastExport` 静态属性（启动时加载）；`Commands.cs` 两个导出命令在导出前写入基础路径 + 子文件夹选项；`CommandsPage.cs` 在 Vue 脚本前注入 `window.__lastExportPath`/`window.__createSubfolder`（用 `JsonSerializer.Serialize` 编码以处理 Windows 反斜杠）；`commands_page.js` 用这两个全局变量初始化并加 `mounted()` 重算目录非空警告。
- 关键点：`SettingsPageGenerator` 会反射 `ExportSettings` 全属性，故**不要**把记忆字段加进 `ExportSettings`，否则会意外生成设置页 UI。新文件独立，无需重跑 `generate.bat`。
