# 2026-09-16 工作日志

## feat(processing): 新增 BundledAssetsExportMode.MainAssetFolder 模式

**需求**：捆绑资源里带原始路径的按原始路径位置导出；没有原始路径的导出到「主资产路径 / 以主资产文件名为名的文件夹」下。
确认口径：主资产 = 资产自身的 `IUnityObjectBase.MainAsset`；两级回退（MainAsset → 所在 bundle 的主资产）；文件夹名去掉扩展名；枚举名 `MainAssetFolder`。

**改动文件**
- `Source/AssetRipper.Processing/Configuration/BundledAssetsExportMode.cs`：新增 `MainAssetFolder`。
- `Source/AssetRipper.Processing/Scenes/OriginalPathProcessor.cs`：`SetOriginalPaths(bundle)` 的 switch 里把 `MainAssetFolder` 与 `DirectExport` 并列（容器里有路径的资源按原始路径导出）。
- `Source/AssetRipper.Processing/MainAssetFolderProcessor.cs`（新增）：两级回退分配 `OriginalDirectory`。
- `Source/AssetRipper.Export.UnityProjects/ExportHandler.cs`：仅在 MainAssetFolder 模式下、注册在**处理器链最后**。
- `Source/AssetRipper.GUI.Web/.../BundledAssetsExportModeDropDownSetting.cs` + `Localizations/{en_US,zh_Hans,zh_Hant}.json`：下拉显示名与描述（key 为 snake_case，生成器转 PascalCase；其他语言缺 key 会自动回退英文）。

### 关键时序坑（下次务必注意）
`IUnityObjectBase.MainAsset` 由 `AssetGroup.SetMainAsset()` 赋值，调用方是：
`PrefabProcessor`(链上第19) / `SpriteProcessor`(20) / `ScriptableObjectProcessor`(21)，
以及 `SceneDefinitionProcessor`(12)、`MainAssetProcessor`(14, 字体/地形)、`AudioMixerProcessor`(16)。
→ 任何依赖 `MainAsset` 的路径逻辑**不能写进 `OriginalPathProcessor`(13)**，必须新处理器注册在链尾。
`MainAsset` 只覆盖：预制体/场景层级里的 GameObject + 组件 + PrefabInstance、SpriteInformationObject、ScriptableObjectGroup；
**AnimationClip / Mesh / Material / AnimatorController 的 MainAsset 为 null**，只能靠 bundle 主资产回退。

### 资源包主资产判定
`bundle.Container` 里 `Asset.FileID == 0`（非共享资产）且 `EnsurePathNotRooted` 非空的条目，优先取文件名（去扩展名）与 bundle 名相同的那个，否则取第一个。
取到后用 `Path.ChangeExtension(path, null)` 得到同名文件夹（如 `Assets/a/b/yyy.prefab` → `Assets/a/b/yyy`）。
