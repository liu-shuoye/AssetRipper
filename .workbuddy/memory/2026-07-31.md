## 完成：用户项目资产替换导出功能（CustomProjectPath）

需求：导出时若用户提供的 Unity 项目/资产文件夹中存在同类型同名资产，直接复制用户源文件+.meta（保留用户 GUID），不再导出反编译版（典型场景：spine 运行时 shader）。

实现（新增 Source/AssetRipper.Export.UnityProjects/UserAssets/ 5 文件 + 修改 6 文件）：
- UserAssetIndex：扫描用户目录（自动检测项目根=扫 Assets/+Packages/一级子目录，否则资产文件夹落 Assets/<目录名>/），解析 .meta guid，建 (类型,名称)→条目 索引
- UserProjectAssetExporter：IAssetExporter，在 ProjectExporter.Overrides.cs DoFinalOverrides 末尾注册（ObjectHandlerStack LIFO，最后注册=最高优先级）
- UserAssetExportCollection：Export 流式复制文件+meta；GUID override 返回用户 GUID；引用指针 MetaPtr(ExportIdHandler.GetMainExportID(asset), 用户GUID, AssetType.Meta)
- v1 支持类型：Shader/Material/MonoScript/Texture2D/AudioClip/TextAsset（MainAsset is not null 排除子资产/多资产集合）
- 设置：ExportSettings.CustomProjectPath；GUI SettingsPage 输入框+浏览按钮（site.js browseForFolder → /Dialogs/OpenFolder）；en_US.json +custom_project_path 键

验证：解决方案构建 0 错误；15 项端到端检查全过（shader 按声明名匹配、GUID 与 UnityGuid.ToString 往返一致、Packages 扫描、大小写不敏感、无 meta 跳过、无效路径降级）。

## 项目环境要点（复用价值）

- 项目目标框架 net10.0，系统 PATH 的 dotnet 仅 9.0；**必须用用户级 SDK：`~/.dotnet/dotnet.exe`（10.0.300）**
- apphost exe 默认找 C:\Program Files\dotnet（无 .NET 10 运行时）；运行构建产物用 `~/.dotnet/dotnet.exe xxx.dll`
- 修改 ExportSettings/ImportSettings/ProcessingSettings 的属性后，**必须手动重跑 AssetRipper.GUI.SourceGenerator**（构建后从其输出目录 Source/0Bins/Other/AssetRipper.GUI.SourceGenerator/Debug 运行 dll，路径是相对该目录的），它同时会把 en_US.json 按键名重排序
- Localizations/en_US.json 加键后，Localization 属性由 Roslyn 增量生成器构建时自动生成，无需手改
- AssetRipper.Primitives 的 UnityGuid.Parse 走 System.Guid 格式，**不能解析 .meta 的 32 位 hex**；解析需自实现（与 ToString 互逆：每 uint 自低位 8 个 nibble），实现在 UserAssetIndex.TryParseGuid
