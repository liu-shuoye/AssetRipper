# 2026-08-03

## 修复：GUI.Web 反射式 JsonSerializer 序列化异常
- 异常：`InvalidOperationException: Reflection-based serialization has been disabled` 出现在 `CommandsPage.WriteScriptReferences`（`CommandsPage.cs:102`）。
- 根因：应用禁用了反射式 System.Text.Json（`JsonSerializer.Serialize(value)` 无 `TypeInfoResolver` 会抛异常）。`LastExportSettings` 自身已用源生成上下文 `LastExportSettingsContext`，但 CommandsPage 单独序列化 `string`/`bool` 时用了反射式 API。
- 修复：改用 GUI.Web 已有的 `AppJsonSerializerContext.Default.String` / `.Boolean` 进行源生成序列化（该上下文已注册 `string`、`bool` 等类型，`Dialogs.cs`/`WebApplicationLauncher.cs` 中验证可用）。
- 经验：在本项目（net10 + 禁用反射序列化）中，任何 `JsonSerializer.Serialize/Deserialize` 都必须传入 `JsonSerializerContext.Default.Xxx`，禁止裸调用。
