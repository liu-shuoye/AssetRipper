# 2026-08-01

## 修复：CS0117 Localization 不含 CustomProjectPath
- 现象：`AssetRipper.GUI.Web` 编译报错 `CS0117 "Localization"未包含"CustomProjectPath"的定义`（SettingsPage.cs:230）。
- 根因：`Localization` 类由源生成器（`AssetRipper.GUI.Localizations.SourceGenerator/LocalizationGenerator.cs`）从 `Localizations/*.json` 生成。键 `custom_project_path` 已存在于 `Localizations/en_US.json`（snake_case→PascalCase 得 `CustomProjectPath`）。但生成的 `Localization.g.cs` 时间戳(07-30)早于 en_US.json 修改时间(08-01)，MSBuild 把 Localizations 工程判为 up-to-date 未重新生成，Web 编译用了旧的 `Localization.dll`。
- 修复：删除 `Source/0Bins/obj/AssetRipper.GUI.Localizations` 与 `Source/0Bins/Other/AssetRipper.GUI.Localizations`，重新 `dotnet build AssetRipper.GUI.Localizations.csproj`，再 build `AssetRipper.GUI.Web.csproj` → 0 错误。
- 经验：改了 `Localizations/*.json` 后若 Web 报 CS0117，多半是源生成器缓存未刷新，清理 Localizations 的 obj/bin 重新生成即可。
